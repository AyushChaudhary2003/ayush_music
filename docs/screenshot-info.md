# Screenshot Information

The screenshot.png file should be added to this directory to display in the README.

## To add the screenshot:

1. Save your application screenshot as `screenshot.png` in this `docs/` directory
2. Ensure the file is named exactly `screenshot.png`  
3. Commit and push the file to GitHub

## Alternative: Use an image hosting service

If you prefer, you can upload your screenshot to:
- GitHub Issues (drag & drop to get a GitHub URL)
- Imgur
- Cloudinary
- Any other image hosting service

Then update the README.md file with the direct URL.
